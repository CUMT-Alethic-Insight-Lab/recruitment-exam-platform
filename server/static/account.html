机试指引

  1. 在考试机上下载并解压机试安装包，双击启动器 AlethicInsight社团招新机试平台（自检通过后会拉起作答环境与上传界面）。
  2. 在清洗上传界面的学号登录入口，用本账号（学号 + 密码）登录，云端校验通过后自动下发按你领域配置的题目。
  3. 首次登录的初始密码 = 学号，请登录后尽快在上方修改密码。
  4. 机试共三条轨迹：研发型 / 实操型 / 自由创作，不限时长，允许使用任意 AI 工具与资料（模型可接入自己的 API）。
  5. 完成后点击「结束并上传」，会话清洗件将自动上传云端；若上传失败会保留本地并在界面醒目提示。

自由创作请在上传时填写 GitHub 链接，评审将结合会话记录与仓库进行。
