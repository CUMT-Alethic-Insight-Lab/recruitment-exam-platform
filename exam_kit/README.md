# Alethic Insight 社团招新 · 机试考生指南

机试在你**自己的电脑**上完成：本考试系统负责发题、换题和交卷时清洗上传你的作答记录；
**作答在 AI 工具里进行**——按安装时选择，使用 **Kimi Code** 或 **opencode** 之一（本指南里统称「AI 工具」）。

> 声明：本考试系统只上传**清洗后的会话记录**（已去除思考过程与工具输出正文），不上传你电脑里的其他文件。
> Kimi Code（Moonshot）与 opencode 均为第三方软件，与本社团无关。
> Kimi Code 需要自备模型（会员或 API Key）；opencode 的免费模型是 **OpenCode Zen 的限时免费型号**
> （如 Big Pickle、MiMo-V2.5 Free 等）——**仍需先联网注册 Zen 账号拿 API key，再在 opencode 里执行
> `opencode auth login` 登录**，之后用免费模型不收费；并非"完全免登录"。首次配置需要联网。

## 第一步：启动考试系统

1. 把「招新考试系统」文件夹**完整解压**到桌面（不要只解压部分文件）。
2. 双击文件夹里的 **`启动考试系统`**：
   - 会弹出「机试服务」黑色窗口——**不要关它**，最小化即可；
   - 浏览器会自动打开机试页面（http://127.0.0.1:8899）；
   - 还会新开一个 AI 工具窗口（Kimi Code 或 opencode 的网页作答界面）。
   - 端口说明：opencode 作答界面固定使用 **8898** 端口（`opencode web` 默认是随机端口，
     启动脚本已通过 config.json 的 `opencode_web_cmd` 显式指定 `--port 8898`，
     避开考试页 8899 与 kimi web 的 58627）。
3. 如果双击后提示缺少 Python，先运行安装程序完成安装再重试。

## 第二步：登录、看题、作答

1. 在机试页面输入**学号 + 密码**登录（**初始密码 = 学号**，可在招新平台网页端修改；
   仍用初始密码时页面会提示）。
2. 选择答题轨迹（研发型 / 实操型 / 自由创作型）。你的考试方式以报名时选择为准（见下文）。
3. 看完题目，点 **「我已理解，开始在 AI 工具里作答」**，然后切到 AI 工具窗口开始答题。
4. 答题过程不限时；不满意可回页面点「换题」（默认限 2 次）。

### 自选题模式（可选）

随机抽题之外，你也可以从公开题库里自己挑题：

1. 在轨迹选择页点「**浏览题库自选题**」——页面按轨迹/领域分组展示全部开放题目。
2. 勾选 **1~3 道**题（勾选顺序即作答顺序），点「确认自选开考」。
3. 自选题模式下没有「换题」按钮：题目是你自己选的，确需更换请联系组织者。
4. 不点自选、直接点轨迹按钮，则为原来的随机抽题（含换题次数）。

## 第三步：交卷（一键完成）

1. 在 AI 工具里答完题后，**回到机试页面**。
2. 可选：填 GitHub 仓库链接，或上传一个 zip 附件（≤50MB）；两项都可留空。
3. 点绿色超大按钮 **「清洗并上传我的作答」**。系统会自动找到你的作答会话，
   清洗后上传云端——看到绿色 **「✔ 交卷成功」** 就完成了。
   （opencode 考生：系统直接读取 opencode 的本地数据库 `opencode.db`
   自动发现你的作答会话，正常情况下**无需手动导出**。）
4. **失败了也不怕**：红色提示框会用白话告诉你原因，点「重试上传」即可。
   若提示"没找到你的作答记录"，请确认你是在「考试工作目录」文件夹里用 AI 工具完成的作答；
   opencode 考生也可以用提示框里的「手动选择会话文件」选中导出的会话 JSON 文件兜底。
5. **断网兜底**：交卷时网络不通，清洗后的记录会自动保存在 `pending_upload/` 文件夹，
   恢复网络后点「重试上传」，或保持页面开着自动补传，无需手动操作。

## 三种考试方式

报名问卷中选择的方式决定你如何完成机试，登录后页面会自动按你的方式展示对应入口：

- **标准机试（standard）**：即本文档描述的完整流程——在本机用 AI 工具作答随机抽取（或自选）的题目，
  交卷时自动清洗上传会话记录。可选补充材料（GitHub 链接或 zip 附件）。
- **个人项目（own_project）**：**无需使用本机考试系统**。报名后在招新平台网页端
  「个人中心（账号页）」提交你的 GitHub 仓库链接，提交成功即视为完成机试交付。
  请确认仓库为公开（或已授予评审权限）且包含完整说明。
- **自由发挥（free_creation）**：在所选领域内自由创作，**仍走标准机试流程**
  （本机 AI 工具作答 + 会话记录上传），交卷时把作品 GitHub 链接填入补充材料一并提交。

## 常见问题

- **卸载**：把桌面「招新考试系统-删除文件夹即完成卸载」文件夹删掉就是卸载，
  本考试系统不写注册表、不留任何系统设置。
- **机试包目录下的 `state.json` 含登录凭证（auth_token），请勿外传或发给别人**；机试结束后可整包删除。
- **提示无法连接云端**：检查网络；确认 config.json 里 `cloud_base` 是组织者给的地址
  （应为 `https://alethicinsight.com/recruitment`）。
- **交卷时提示没找到作答记录**：确认你是在点「我已理解，开始在 AI 工具里作答」**之后**、
  在「考试工作目录」文件夹里用 AI 工具答题的；确实答过的话，opencode 考生可用
  「手动选择会话文件」兜底，或联系组织者，不要重复交卷。
- **交卷后显示"还没传到云端"**：说明记录已安全保存在本地，只是暂时没能上传（多为断网）。
  恢复网络后点「重试上传」，或保持服务运行即可自动补传。
- **换浏览器/意外关页面**：直接重新打开 http://127.0.0.1:8899 即可恢复进度（服务窗口别关）。
- **想换 AI 工具**：工具选择在安装时确定（config.json 的 `agent` 字段：`kimi` 或 `opencode`），
  两个都装了的话可自行修改 config.json 后重启「启动考试系统」。opencode 的启动指令
  在 config.json 的 `opencode_web_cmd`（默认 `opencode web --port 8898`，固定端口请勿删掉 `--port`，
  否则 opencode 会用随机端口）。

## 组织者 · 局域网交卷模式（upload_mode=lan）

云端入口带宽有限时，可让交卷文件不占公网流量：登录/抽题等仍走云端公网入口，
只有清洗后的轨迹文件与附件上传到考场局域网的一台接收机；云端只收到一个
轻量的「已交卷」标记（几十字节），状态/评分流程不受影响。

1. **接收机**（与考试机同一局域网的任意一台机器，装好 Python）：
   双击本文件夹的 **`启动会话接收服务`**（即 `python session_receiver.py --port 8897`），
   保持窗口开着。存储默认在 `received_sessions/<届次>/<会话ID>/`。
2. **考试机**：把 `config.json` 改两处——
   `"upload_mode": "lan"`、`"lan_receiver_base": "http://<接收机局域网IP>:8897"`，
   然后正常「启动考试系统」。交卷时文件直传接收机；失败照旧落 `pending_upload/` 自动补传。
3. **评审/面试**：浏览器打开 `http://<接收机IP>:8897/` 即列表页——在线看 jsonl/清洗报告、
   下载附件 zip，全程不出局域网。云端管理后台对应会话会显示「局域网」标记，
   评分仍照常在云端后台进行。
4. 可选加固：接收机启动时加 `--token <口令>`，此时仅上传接口需要口令（列表/下载不受影响）；
   仅限可信考场内网使用（明文 HTTP）。考后把 `received_sessions/` 整目录归档即可，
   云端不存文件。
